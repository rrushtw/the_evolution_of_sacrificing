# Phase 2 結果:private↔public 互惠的相圖

> 在一個沒有親緣、死亡罕見(代之以資本/影響力差距)的世界裡,維繫「犧牲」的善良
> 究竟靠 **private history(直接互惠)** 還是 **public reputation(間接互惠)**?
> 答案取決於社會有多流動 —— 而且有一道銳利的相變。

本目錄是正式輸出快照(reboot-safe、納入版控):相圖 1–3 來自 `experiments/phase_sweep.py`
(**環境當主體**);[策略擂台](#策略擂台--主體換成策略自己不吃虧--社會也好)來自
`strategy_arena.py` / `monomorphic_sweep.py` / `sweet_spot.py`(**策略當主體**)。

## 怎麼重現

```bash
docker compose run --rm \
  -e REPS=30 -e BATCH_GENERATIONS=300 \
  -e CHURN_GRID=0.0,0.1,0.3,0.6,1.0 \
  -e RANDOM_SEED=12345 -e JOBS=22 \
  simulator python -u experiments/phase_sweep.py
```

- **n=30** replicates/cell、**95% CI**、`RANDOM_SEED=12345`(replicate *i* 用 seed `12345+i`,可重現)。
- `CHURN_RATE` = 村莊↔都會旋鈕:0 = 固定圈子(常重逢)、→1 = 不斷重組(盡是陌生人)。
- knockout:`none` / `−reputation`(隱藏公共名聲+公開行為紀錄)/ `−private`(不記逐對手記憶)。
- 合作指標 = 「聲望型善良策略」的族群佔比(`nice%`)。

## 統一框架

合作演化三大機制同一道門檻 **`機制強度 > c/b`**,折扣因子:`r`(結伴)、`w`(再相遇/private)、
`q`(名聲/public)。奇異點 `r* = c/((1−s)b) ≈ 0.21`(= Hamilton 法則,把基因換成名聲)。

## 相圖 1 — 14 策略 baseline

`nice%`(mean ± 95% CI, n=30、`RANDOM_SEED=12345`)。原始 console / JSON 不入版控(見[怎麼重現](#怎麼重現),固定 seed 可重跑得同數)。

| churn | 再相遇率 | none | −reputation | −private |
| :--: | :--: | :--: | :--: | :--: |
| 0.0 村莊 | 65% | 79%±12% | 78%±10% | 72%±11% |
| 0.1 | 30% | 74%±13% | 71%±11% | 68%±12% |
| 0.3 | 6% | 57%±16% | **2%±3%** | 42%±16% |
| 0.6 | 7% | 54%±16% | **7%±9%** | 45%±16% |
| 1.0 都會 | 7% | 59%±15% | **9%±10%** | 54%±17% |

**結論**:相變落在 churn 0.1→0.3 之間(再相遇率 30%→6%)。
- **村莊**(低 churn):關掉名聲或私人記憶,合作幾乎不掉 —— 穩定的人際網結構(固定圈子 +
  剝削就斷裂)本身就撐住合作。
- **都會**(高 churn):**公共名聲是唯一命脈** —— 關掉它,合作崩到 2–9%(CI 極窄);
  關掉私人記憶只小掉,因為你幾乎不重逢,private 記憶沒有對象可用。

→ **社會越流動,維繫合作的機制就從「結構/直接互惠」交棒給「名聲/間接互惠」。**

## 相圖 2 — 16 策略(加入 Clannish + Whitewasher)

新增兩個直擊 Phase 2 機制的策略:
- **Clannish(排外者)**:NOTIFY 給有私人交情者、RUN 給陌生人 → 村莊好鄰居 / 都會掠食者。
- **Whitewasher(洗白者)**:自己 GOOD 就 RUN 套現、變 BAD 就 NOTIFY 洗白 → 攻擊名聲管道本身。

`nice%`(mean ± 95% CI, n=30、`RANDOM_SEED=12345`)。原始 console / JSON 不入版控(見[怎麼重現](#怎麼重現),固定 seed 可重跑得同數)。

| churn | none | −reputation | −private | none 對比 14 策略 |
| :--: | :--: | :--: | :--: | :--: |
| 0.0 村莊 | 80%±10% | 80%±10% | 67%±11% | 持平 |
| 0.1 | 76%±10% | 72%±12% | 66%±13% | 持平 |
| 0.3 | 54%±15% | **1%±1%** | 46%±16% | 略降 |
| **0.6 城鄉移民** | **31%±13%** | **1%±1%** | 49%±15% | **54%→31% 腰斬** |
| 1.0 都會 | 53%±15% | **0%±0%** | 43%±15% | 略降 |

剝削/回合(none):churn 0.6 由 14 策略的 **9.3 暴增到 22.9**。

**三個發現,兩個假設皆證實且更強**:

1. **Whitewasher 讓名聲更不可或缺。** 加入洗白者後,關掉名聲的都會合作從 ~9% **歸零(0%±0%)**。
   一個 gaming 名聲的掠食者,反而讓社會**更依賴**名聲系統 —— 防線一旦失守,合作蕩然無存。
   (對應現實:假訊息/洗評價時代,對「可信名聲」的依賴不減反增。)

2. **Clannish 把「城鄉移民」中間態打成重災區。** churn 0.6 的合作 **54%→31%(腰斬)**、剝削率 **9→23**。
   **最慘的不是純都會,而是半流動的過渡帶** —— 流動性夠高讓掠食者一直找到新肥羊並逃逸,
   結構又還沒散到大家互不信任。呼應「城鄉移民」直覺:**半流動社會最易被剝削。**
   (churn 軸其實就是城鄉移民的兩型光譜:**候鳥族(半返鄉,固定圈子還在)** 落在低 churn 一端、
   仍靠直接互惠撐住合作;**落腳都市(單向移居,連結已斷)** 落在高 churn 一端、只剩公共名聲可恃 ——
   而過渡帶正卡在兩者之間,最脆弱。)

3. **村莊穩如泰山。** churn 0–0.1 幾乎不變 —— Clannish 在固定圈子裡乖乖當好鄰居,
   Whitewasher 也玩不太動。

## 相圖 3 — A1:c/b 社會 preset,量 `r*` 平移

前兩張圖固定 payoff、只掃 churn(改的是 `w`/`q` 折扣)。這張反過來:**固定 churn 軸,改社會的
`c/b` 比值** —— 因為「不同社會」的本質就是發聲成本 `c` 與被警告收益 `b` 的比值不同,而門檻
`r* = c/((1−s)b)` 直接隨之平移。零新數學,只動四個 `SURVIVAL_*` payoff 常數,收成幾組具名 preset
(`SOCIETY_PRESET` 旋鈕,`s = 0.5` 全程固定):

| preset | 旋鈕變動 | c | b | 理論 `r*` |
| :-- | :-- | :--: | :--: | :--: |
| `cheap_voice` 低成本發聲 | NOTIFY 存活 0.9→0.97 | 0.03 | 0.95 | **0.06** |
| `default` 現狀 | —— | 0.10 | 0.95 | **0.21** |
| `safety_net` 現代安全網 | IGNORANT 存活 0.05→0.55 | 0.10 | 0.45 | **0.44** |
| `ancient` 殘酷古代 | NOTIFY 存活 0.9→0.75 | 0.25 | 0.95 | **0.53** |

直覺:**發聲越便宜(`cheap_voice`)、或沒被警告也死不了(`safety_net`)→ 門檻挪動**;
古代世界喊一聲就被掠食者鎖定(NOTIFY 存活率低)→ 合作門檻最高。

`nice%`(none-knockout, mean ± 95% CI, n=30、`RANDOM_SEED=12345`)。原始 console / JSON 不入版控(見[怎麼重現](#怎麼重現),固定 seed 可重跑得同數)。

| churn | `cheap_voice` r*0.06 | `default` r*0.21 | `safety_net` r*0.44 | `ancient` r*0.53 |
| :--: | :--: | :--: | :--: | :--: |
| 0.0 | **66%±11%** | 44%±15% | 34%±9% | **16%±13%** |
| 0.1 | 50%±15% | 44%±15% | 25%±8% | 18%±13% |
| 0.3 | 58%±14% | 37%±15% | 24%±9% | 18%±13% |
| 0.6 | 66%±13% | 26%±13% | 28%±9% | 9%±9% |
| 1.0 | 58%±13% | 38%±16% | 23%±7% | 7%±8% |

**結論 — `c/b` 越高(合作門檻 `r*` 越大),善良策略越難立足。** 固定任一 churn 橫看,`nice%` 幾乎
單調隨 `r*` 反向遞減,排序對齊理論的 `cheap_voice < default < safety_net < ancient`。最乾淨的是
churn=0:**66% → 44% → 34% → 16%**,跨 preset 拉開 50 個百分點。唯一逆轉在 churn 0.6 的
`default`(26%)vs `safety_net`(28%),落在 CI95 重疊內。

→ **同一條 churn 軸,換個社會 preset(只調 payoff)就能讓相變/名聲依賴整體平移** —— 驗證統一框架
裡 `r*` 不只是個常數,而是可被社會結構推動的旋鈕。

## 策略擂台 — 主體換成「策略」:自己不吃虧 × 社會也好

前三張相圖問的是「**什麼社會**讓合作勝出」(環境當主體)。這一節把主體換成**策略本身**,
問一個個人決策者真正關心的問題:**哪個策略最值得我未來採用?** 標準是 **「自己不吃虧 + 社會不崩」**。

需要兩個不同的沙盒、合成兩條軸:

- **X 軸=自己不吃虧**(個人穩健):在 **16 策略生態混戰** 的 60 格命運(4 preset × 5 churn ×
  3 knockout)裡,採用某策略的個體表現 `composite = capital + survived`。散佈軸取**跨命運平均**
  (典型表現);另附 **保底 CVaR**(最壞 5 格平均 = `strategy_arena.py` 的 maximin 主指標)。
- **Y 軸=社會也好**(社會信任):把族群換成 **「全部都是策略 X」的單型社會**,跑到穩態量
  `good_share`(GOOD 名聲佔比 = 信任/合作率)。命運格 = churn(0/0.3/1.0)× knockout
  (none/−reputation/−private)= 9 格,取 **CVaR-maximin**(最壞 3 格 = 「最壞命運下社會還不崩嗎」)。
  *(注意:`nice%` 在單型退化恆 100%/0%,故社會福祉改用行為層的 `good_share`;preset 不納 —— 策略
  `decide()` 看不到 capital/存活參數,preset 只影響 capital、不影響信任率的決策動態。)*

```bash
# 3. 雙軸合成(純讀 melee + mono 兩份 JSON,切象限找甜蜜點)

```

### 三個發現

1. **Sheriff 是唯一兼顧兩端的甜蜜點。** 掠食者(Prober/Cheater)個人典型表現最高(1.3–1.5),
   但全員採用 → 互相背叛、信任崩到 13%(9 格全低信任)。純善良群造就好社會,但個人典型表現
   剛好卡在中位下緣(左上)。**只有 Sheriff 同時站上「個人高於典型 + 社會高信任」。**

2. **Sheriff 的社會「九種命運全不崩」。** 全 Sheriff 社會的 `good_share` 在 churn 0→1、關名聲、
   關私記憶**全部 ~0.98 平坦不動**(它只讀名聲,全好社會裡人人是好人 → 永遠互相吹哨)。對比
   Grudger/Pavlov 在「高流動 + 關名聲」時微跌到 0.94(較依賴記憶去懲罰)。**Sheriff 的好社會最抗命運衝擊。**

3. **`maximin` 抓得出「平常還行、特定社會就崩」的脆弱。** Clannish 社會平均信任 0.67 看似尚可,
   但**最壞 3 格崩到 0.13**;Jacobin 平均 0.42、最壞格 0.13。用「最壞命運」而非「平均」評社會,
   才看得出這種隱藏脆弱 —— 這正是「社會不崩」要的保底視角。

### 一個必須誠實的張力:「不吃虧」有兩種意思

- **要「絕對最壞情況都安全」**(保底 CVaR > 0):**只有掠食者做得到**(Prober 0.15、Clannish、
  Whitewasher)。Sheriff 與所有善良策略保底 CVaR 都是 **0** —— 存在某種殘酷社會(關名聲的高流動
  都會)會把它們團滅。**想要絕對保命,就得當掠食者、接受地獄社會。**
- **接受「比多數人好」就夠**(跨命運典型表現):**Sheriff 是唯一甜蜜點** —— 不會是最有錢的
  (掠食者剝削賺更多),也確有罕見殘酷社會能毀掉你(這對所有好人都成立),但你會**過得比典型好,
  而且大家都學你這招,社會是最互信、最不會崩的**。

→ **這個沙盒給個人決策者的答案:做一個會懲罰壞人的好人(Sheriff)** —— 預設合作、對方佔便宜就果斷
反制。放棄的是「成為剝削別人的首富」與「絕對最壞情況保險」;換來的是「比多數人好的下場 + 一個
換成人人如此也不會崩壞的社會」。

> **前提(務必連同結論讀)**:X 軸沙盒是「16 策略生態混戰」(非兩兩對局、非 invasion),量的是
> 「在當前 16 策略共存社會中」採用某策略的穩健性,**非脈絡無關的內在價值**;增刪策略可能翻盤。
> Y 軸是「固定族群跑到穩態」的信任率,未含世代繁殖/死亡的長期演化(第二版才加 ESS 抗入侵)。

## 入侵 / ESS — 把族群放開繁殖:Sheriff 守得住嗎?救得回嗎?

上一節的甜蜜點是在**固定族群**(不繁殖、不死亡)裡量的,留了一個破口:走進幾個掠食者,Sheriff
壓得住嗎?反過來,在一個**掠食者當道的不信任世界**裡,少數 Sheriff 撐得起來、把社會翻成信任嗎?
這一節放開繁殖/死亡(資本加權繁殖 + 老化/破產死亡,世代重疊),問兩個鏡像問題:

- **防守(ESS 穩定)**:全 Sheriff 社會 + 少數掠食者入侵 → 入侵者份額被壓到 0 = Sheriff 是
  演化穩定策略(ESS)。
- **救贖(殖民翻轉)**:掠食者多數的世界 + 少數 Sheriff → Sheriff 能否從少數茁壯、把社會的
  `good_share`(GOOD 名聲佔比 = 信任率)從低谷拉回 ~1?要看**世代軌跡**。

防守與救贖是同一對策略的鏡像(誰當原住民、誰當入侵者)。掃 4 掠食者 × 雙向 × 入侵種子
{3%,5%,10%,20%} × 9 命運(3 churn × 3 knockout)× n=30 = **8640 runs**。

### 怎麼重現(入侵 / ESS)

```bash

  -e INV_KNOCKOUTS=none,-reputation,-private \
  -e INV_PREDATORS=Cheater,Prober,Whitewasher,Clannish \
  -e RANDOM_SEED=12345 \
  simulator python -u experiments/invasion.py
```

### 防守:Sheriff 是 ESS —— 但有一個條件

入侵者末份額被清到 0 的比例(`invader_extinct`,n=30、所有種子 3→20% × 所有 churn 聚合):

| 對手 | `none` | `−private` | `−reputation` 蒙眼 |
| :-- | :--: | :--: | :--: |
| Cheater | **1.00 全守住** | **1.00** | 0.00–0.33 多數**反被入侵** |
| Prober | **1.00** | **1.00** | 0.00–0.33 反被入侵 |
| Whitewasher | **1.00** | **1.00** | 0.00–0.50 反被入侵 |
| Clannish | **1.00** | **1.00** | 0.00–0.53 反被入侵 |

**只要名聲管道看得見(`none` / `−private`),全 Sheriff 社會就是磐石** —— 四個掠食者、入侵種子
大到 20%、所有流動度,**全部 100% 守住**(每格 30/30 reps 都 `resisted`)。私人記憶關掉不影響,
因為 Sheriff 根本不靠它 —— **它只讀公共名聲**。

**但 ESS 不是無條件的:關掉名聲(`−reputation`),Sheriff 連自家都守不住。** 蒙眼後它認不出
掠食者、把對方當好人吹哨幫忙 → 被剝削 → 守住率崩到 0.0–0.5,多數格反被入侵。
**Sheriff 的 ESS 地位,完全押在「名聲看得見」這一個條件上。**

### 救贖:需要臨界質量,而且做得到

少數 Sheriff 入侵掠食者世界、能不能翻成信任?**能,但要夠多人**(`none`-knockout,「✔ 真翻轉」
= 多數 run `redeem_win` 且 `good_share` 由低谷翻過 0.5):

| 對手 | churn 0.0 村莊 | churn 0.3 | churn 1.0 都會 |
| :-- | :--: | :--: | :--: |
| Cheater | **10% ✔** | 20% ✔ | 20% ✔ |
| Prober | **10% ✔** | 20% ✔ | 20% ✔ |
| Clannish | ✗(20% 仍卡共存) | 20% ✔ | 20% ✔ |
| Whitewasher | ✗ | 份額勝但信任未真翻 | 同左 |

- **3~5% 的零星 Sheriff 一律失敗** —— 還沒彼此會合、形成互助前就被掠食者磨到滅絕。要約 **1/5
  的人**一起,才站得穩、滾雪球翻盤。「一個人改變不了世界,但一場運動可以」的數學版。
- **乾脆背叛的掠食者(Cheater/Prober)最好救**:被標 BAD 最快,10% 就能翻村莊、20% 翻所有流動度。
- **Whitewasher(洗白者)最難救** —— 它「好就背叛、壞就洗白」專門污染 Sheriff 賴以判斷的名聲管道,
  讓 `good_share` 永遠假性停在 ~0.55(看似還行、其實是被刷出來的)。連 20% Sheriff 也只能把份額
  推到 0.4–0.6,信任翻不乾淨。
- **Clannish(排外者)在村莊(churn 0)最難撼動** —— 它在固定圈子裡是稱職好鄰居,20% Sheriff 仍
  卡在共存;但高流動下(churn 1.0)它的「認親」失靈、20% 就翻得動。關掉私記憶(`−private`)廢掉
  它的認親能力 → 連村莊都救得回(翻轉率 0.47→0.83)。
- **關掉名聲(`−reputation`)→ 救贖全盤失敗**(翻轉率平均 0.03、Sheriff 末份額 ~0)。

### 救贖弧線:社會得先看見自己的腐敗,執法者才救得回

代表性軌跡(seed=12345,Sheriff 20% 入侵,`none`-knockout,42 欄下採樣):

```
Sheriff 20% → Cheater 世界 (churn 0, 82 代)
  Sheriff份額 ▂▂▂▂▂▂▃▃▃▃▃▃▃▃▄▄▅▅▅▅▅▆▆▆▆▇▇▇▇▇████████████  0.20 → 1.00
  good_share  █▄▃▃▃▃▃▃▃▃▃▃▃▄▄▄▅▆▆▅▅▆▆▆▆▇▇▇▇▇▇███████████  1.00 ↘ 0.26 ↗ 0.99

Sheriff 20% → Prober 世界 (churn 0, 116 代)
  Sheriff份額 ▂▂▂▃▃▃▃▃▃▃▄▄▅▄▅▅▅▆▆▆▆▆▆▇▇▇████████████████  0.20 → 1.00
  good_share  █▄▃▃▃▃▃▃▃▄▄▄▅▄▅▅▅▆▆▆▆▆▆▇▇▇████████████████  1.00 ↘ 0.28 ↗ 0.98
```

`good_share` 必先從起手的 1.0(無罪推定、人人預設 GOOD)**跌到谷底 ~0.26**(掠食者陸續 RUN-on-GOOD
被標 BAD、社會認清現實),Sheriff 才認得出敵人、開始反制、靠互助累積資本、資本加權繁殖滾大,
最後把信任拉回 ~0.99。**信任不能靠天真維持,要靠「看得見壞人並懲罰他」的機制重建。**

### 一條貫穿全研究的主軸:名聲可見性是唯一樞紐

防守與救贖,**兩個方向都鉸在同一根軸上 —— 名聲看不看得見**:

| | 名聲看得見(`none`/`−private`) | 名聲蒙眼(`−reputation`) |
| :-- | :-- | :-- |
| **防守** | ESS 磐石,100% 守住 | 守不住,反被入侵 |
| **救贖** | 臨界質量(~1/5)就翻得動 | 全盤失敗 |

呼應相圖 1–2 的核心結論:**在流動、匿名的社會裡,公共名聲是合作的命脈。** 這裡用第三種方式
再證一次 —— Sheriff 這個「會懲罰壞人的好人」之所以能守、能救,靠的全是那條名聲管道;蒙上眼,
連執法者也無力回天。

### 必須誠實的範圍與張力

- **ESS 是有條件的**,不是無條件:它成立於「名聲可觀測」的前提下。標題寫「Sheriff 是 ESS」時
  必須連這個前提一起講,否則就是過度宣稱。
- **份額翻轉 ≠ 信任翻轉**:Whitewasher 世界裡 `good_share` 被洗白刷成假性 ~0.55,
  「`redeem_win`(份額勝)」未必等於「社會真的變可信」。兩者會分岔,本節分開標示。
- **只測 default preset、且為兩物種對局**(resident + invader),非 Sheriff 入侵 16 策略混合
  生態。資本加權繁殖下 preset 會影響動態,結論別外推到其他 payoff / 多物種雜燴。
- **臨界種子是離散掃描**(3/5/10/20%),真正的臨界值落在格與格之間;近臨界格方差最大,故看
  30 reps 的結局票數而非單一 run。
- **下一步(#6 第三方制度懲罰)**:即使 Sheriff 達 ESS,仍要觀察「系統主動淘汰 BAD」這類外部制度
  對生態的影響 —— 需要動引擎加機制,是本研究確認的後續方向。
