# Phase 2 結果:private↔public 互惠的相圖

> 在一個沒有親緣、死亡罕見(代之以資本/影響力差距)的世界裡,維繫「犧牲」的善良
> 究竟靠 **private history(直接互惠)** 還是 **public reputation(間接互惠)**?
> 答案取決於社會有多流動 —— 而且有一道銳利的相變。

本目錄是正式輸出快照(reboot-safe、納入版控):相圖 1–3 來自 `experiments/phase_sweep.py`
(**環境當主體**);[策略擂台](#策略擂台--主體換成策略自己不吃虧--社會也好)來自
`strategy_arena.py` / `monomorphic_sweep.py` / `sweet_spot.py`(**策略當主體**)。

## 研究故事(整條線一次讀完)

> 全研究的一條敘事線:為什麼這樣設計、發生了什麼、最反直覺的是什麼。數據、表格、誤差帶都在底下各章,
> 這一節只串故事線。配圖(6 張 PNG)由 `experiments/plot_results.py` 純讀 JSON 生成,隨 release 附上(不入版控)。

1. **起點:為什麼天擇一定要是「死亡」。** 一個早期版本曾把選擇機制設成「每代淘汰墊底的 k 個」,
   看似與死亡等價,其實抽掉了研究的靈魂:少了真實的生存壓力,「犧牲」就不再有代價,善良能否存活的問題
   形同虛設。本研究改回**入不敷出就餓死的死亡天擇**,並以它為 **Baseline 0** —— 殘酷但真實,後面一切才站得住。

2. **一把尺量三種合作。** 親緣、直接互惠、間接互惠,演化生物學各講各的;本研究把它們收進**同一道門檻**
   `機制強度 > c/b`(見 [統一框架](#統一框架))。三把鑰匙 `r`(結伴)、`w`(再相遇 / private)、
   `q`(名聲 / public),奇異點 `r* ≈ 0.21` 就是 **Hamilton 法則把基因換成名聲**。全程刻意**不碰基因 / 親緣**
   —— 那是已知會逼出自私的支線,留作未來。

3. **Phase 1→2 的轉折:解封 `w` 與 `q`。** one-shot(每次都遇陌生人)讓再相遇 `w` 休眠,私記憶與名聲都派不上用場。
   Phase 2 用兩件事解封:**資本 / 影響力差距**取代罕見的死亡(誰富、誰繁殖),加上**會流動的人際網**
   —— 同一圈子常重逢(村莊)、或不斷重組盡是陌生人(都會)。再補一條真實動機:**剝削→關係斷裂→加害者流走**,
   讓「打帶跑」逃過私下報復,逼出名聲的用武之地。

4. **核心發現:流動度決定合作靠誰。** 社會越流動,維繫合作的命脈就從**結構 / 直接互惠**交棒給**名聲 / 間接互惠**,
   中間有一道**銳利相變(churn 0.1→0.3)**(見下方〈相圖 2〉)。都會裡關掉名聲,善良崩到近 0;村莊裡關任一管道都還撐得住
   —— 但統一重跑後才看清,村莊撐得住有一半是 `assortment`(結伴)的功勞:**結構與名聲是部分替代品**。

5. **兩個反直覺。** (a) **Whitewasher(洗白者)攻擊名聲,反而讓社會更依賴名聲** —— 都會關名聲時善良從 ~9%
   被它壓到 0%。(b) **最慘的不是純都會,是半流動的「北漂」過渡帶**(churn 0.6):結構已鬆、名聲未立,
   剝削 / 回合飆到最高,正是最容易被佔便宜的社會。

6. **主體一換,問題從「社會」變「個人」。** 前半問「什麼社會讓合作勝出」;後半改問「**哪個策略最值得我這個人採用**」。
   雙軸(個人不吃虧 × 社會不崩)合成出**唯一的右上甜蜜點:Sheriff** —— 會懲罰壞人的好人
   (見 [策略擂台](#策略擂台--主體換成策略自己不吃虧--社會也好))。放開繁殖測抗入侵,Sheriff **是 ESS、也救得回腐敗社會,
   但全押在一個條件:名聲看得見**(蒙眼就守不住、也救不回)。最後加上**第三方制度**:都會關名聲時制度能把信任從
   1% 救到 ~80%,但**誤判率一高就反噬** —— 制度是名聲的替補,不是免費的萬靈丹。

**一句話**:抽掉親緣後,會犧牲的善良要活下來、甚至獨佔,靠的是**讓背叛被看見** —— 結構、記憶、名聲、制度,
都是同一件事的不同實作;社會越匿名流動,名聲就越是唯一的命脈。

**限制(務必連著結論讀)**:`nice%` 量的是**族群組成**而非總福利;個人擂台是「16 策略混戰」下的相對穩健,
非脈絡無關的內在價值,增刪策略可能翻盤。完整範圍與張力見各章末的「誠實」段落。

## 怎麼重現

```bash
docker compose run --rm \
  -e REPS=30 -e BATCH_GENERATIONS=300 \
  -e CHURN_GRID=0.0,0.1,0.3,0.6,1.0 \
  -e RANDOM_SEED=12345 -e JOBS=22 \
  simulator python -u experiments/phase_sweep.py
```

- **n=30** replicates/cell、**95% CI**、`RANDOM_SEED=12345`(replicate *i* 用 seed `12345+i`,可重現)。
- `CHURN_RATE` = 村莊↔都會旋鈕:0 = 固定圈子(常重逢)、→1 = 不斷重組(盡是陌生人)。
- knockout:`none` / `−reputation`(隱藏公共名聲+公開行為紀錄)/ `−private`(不記逐對手記憶)。
- 合作指標 = 「聲望型善良策略」的族群佔比(`nice%`)。

## 統一框架

合作演化三大機制同一道門檻 **`機制強度 > c/b`**,折扣因子:`r`(結伴)、`w`(再相遇/private)、
`q`(名聲/public)。奇異點 `r* = c/((1−s)b) ≈ 0.21`(= Hamilton 法則,把基因換成名聲)。

## 相圖 2 — 16 策略 × 結構(assortment)軸:結構與名聲是「部分替代品」

新增兩個直擊 Phase 2 機制的策略:
- **Clannish(排外者)**:NOTIFY 給有私人交情者、RUN 給陌生人 → 村莊好鄰居 / 都會掠食者。
- **Whitewasher(洗白者)**:自己 GOOD 就 RUN 套現、變 BAD 就 NOTIFY 洗白 → 攻擊名聲管道本身。

並把**結伴傾向 `assortment`** 升為**顯式掃描軸**(`ASSORTMENT` 旋鈕:0 = well-mixed 隨機相遇、
0.6 = 同類強結伴)。assortment 正是統一框架裡的折扣因子 `r`(Hamilton 法則把基因換成 Standing):
**同 Standing 的人更容易相遇 → 合作者自然成團、彼此餵養。** 這一掃直接回答核心問題:
**結構(`r`)與名聲(`q`)誰能替代誰?**(早期相圖 1/2 經 `.env` 默吃 `ASSORTMENT=0.6`,此版已改為
顯式三組重跑,2026-06-04 於遠端 20 核跑完,n=30。)

`nice%`(mean ± 95% CI, n=30、`RANDOM_SEED=12345`、`PRESETS=default`、16 策略全集)。粗體 = 關掉名聲。

**assortment 0.0(well-mixed,結構完全不幫忙)**

| :--: | :--: | :--: | :--: |
| 0.0 村莊 | 43%±16% | **5%±5%** | 53%±16% |
| 0.1 | 35%±14% | **3%±5%** | 35%±15% |
| 0.3 | 51%±17% | **0%** | 34%±16% |
| 0.6 | 34%±14% | **0%** | 45%±16% |
| 1.0 都會 | 27%±13% | **0%** | 41%±16% |

**assortment 0.3(中度結伴)**
| churn | none | −reputation | −private |
| :--: | :--: | :--: | :--: |
| 0.0 村莊 | 74%±11% | **66%±11%** | 75%±12% |
| 0.1 | 78%±12% | **45%±14%** | 66%±14% |
| 0.3 | 50%±16% | **0%** | 62%±14% |
| 0.6 | 54%±16% | **0%** | 26%±14% |
| 1.0 都會 | 43%±16% | **0%** | 46%±16% |

**assortment 0.6(強結伴,合作者成團)**
| churn | none | −reputation | −private |
| :--: | :--: | :--: | :--: |
| 0.0 村莊 | 70%±12% | **82%±7%** | 77%±10% |
| 0.1 | 74%±11% | **75%±11%** | 79%±10% |
| 0.3 | 41%±16% | **2%±3%** | 31%±13% |
| 0.6 | 28%±14% | **2%±2%** | 35%±14% |
| 1.0 都會 | 45%±16% | **0%** | 50%±16% |

> **一眼看懂「部分替代品」**:對照三張表的 **−reputation 欄(關掉公共名聲)**。assortment 0.0 **全 churn 趨近 0** ——
> 沒結構又拿掉名聲,合作無從立足;assortment 0.6 在**村莊**(churn≤0.1)仍撐 **75–82%**,
> **結構替代了名聲**;但一過 churn 0.3,連強結伴也壓不住流動帶來的匿名,**塌回 ~0**。
> → **結構與名聲是部分替代品:低流動可互換,高流動只有名聲頂得住。**

**三個發現**:

1. **結構替代名聲,但有效範圍只在村莊。** 關掉公共名聲後:well-mixed(assort 0)全 churn 崩到 **0–5%**;
   強結伴(assort 0.6)在村莊還有 **75–82%**,**但 churn≥0.3 一樣塌到 ~0**。→ 結構(直接互惠 `r`)與
   名聲(間接互惠 `q`)互為**部分**替代 —— **低流動可互換,高流動只剩名聲。** 這同時標出了
   第三方制度要補的正是「**高流動 × 名聲失效**」這一格(見下方 **第三方制度懲罰** 章節)。

2. **Whitewasher 讓名聲在高流動更不可或缺。** 任一 assortment,churn≥0.3 關掉名聲都歸零 —— 一個
   gaming 名聲的掠食者,反而讓流動社會**更依賴**可信名聲。(現實對照:假評價/假訊息時代,對可信
   名聲的依賴不減反增。)

3. **結伴同時墊高「完整機制」的村莊合作。** none 欄村莊:assort 0→**43%**、0.3→**74%**、0.6→**70%**。
   結構讓合作者成團、彼此餵養,村莊整體合作墊高約 30 個百分點。

下面兩張是 **assortment 0.0(well-mixed)單獨切面** —— 純看名聲、結構完全不幫忙的最嚴格基準:

> **well-mixed 的殘酷版**(上方 assortment 0.0 表):沒有結伴幫忙,**關掉公共名聲後合作全程趨近 0,
> 連村莊都救不回** —— 在隨機相遇的大社會裡,名聲是合作唯一的地基。

**社會剖面(assortment 0,`none`)**:

| churn | 0.0 | 0.1 | 0.3 | 0.6 | 1.0 |
| :-- | :--: | :--: | :--: | :--: | :--: |
| 再相遇率 | 49% | 28% | 6% | 5% | 5% |
| 剝削/回合 | 25.4 | 26.1 | 18.4 | 20.9 | 24.3 |

> **well-mixed 的殘酷**:再相遇率隨流動從 ~49% 崩到 ~5%;但剝削/回合**全程居高不下(~18–26)** ——
> 沒有同類結伴的保護,連村莊也擋不住打帶跑。對照需要結構才壓得低剝削(見上方三表的 `none` 欄:
> 結伴越強、村莊合作越高)。

## 相圖 3 — A1:c/b 社會 preset,量 `r*` 平移

前兩張圖固定 payoff、只掃 churn(改的是 `w`/`q` 折扣)。這張反過來:**固定 churn 軸,改社會的
`c/b` 比值** —— 因為「不同社會」的本質就是發聲成本 `c` 與被警告收益 `b` 的比值不同,而門檻
`r* = c/((1−s)b)` 直接隨之平移。零新數學,只動四個 `SURVIVAL_*` payoff 常數,收成幾組具名 preset
(`SOCIETY_PRESET` 旋鈕,`s = 0.5` 全程固定):

| preset | 旋鈕變動 | c | b | 理論 `r*` |
| :-- | :-- | :--: | :--: | :--: |
| `cheap_voice` 低成本發聲 | NOTIFY 存活 0.9→0.97 | 0.03 | 0.95 | **0.06** |
| `default` 現狀 | —— | 0.10 | 0.95 | **0.21** |
| `safety_net` 現代安全網 | IGNORANT 存活 0.05→0.55 | 0.10 | 0.45 | **0.44** |
| `ancient` 殘酷古代 | NOTIFY 存活 0.9→0.75 | 0.25 | 0.95 | **0.53** |

直覺:**發聲越便宜(`cheap_voice`)、或沒被警告也死不了(`safety_net`)→ 門檻挪動**;
古代世界喊一聲就被掠食者鎖定(NOTIFY 存活率低)→ 合作門檻最高。

`nice%`(none-knockout, mean ± 95% CI, n=30、`RANDOM_SEED=12345`)。原始 console / JSON 不入版控(見[怎麼重現](#怎麼重現),固定 seed 可重跑得同數)。

| churn | `cheap_voice` r*0.06 | `default` r*0.21 | `safety_net` r*0.44 | `ancient` r*0.53 |
| :--: | :--: | :--: | :--: | :--: |
| 0.0 | **66%±11%** | 44%±15% | 34%±9% | **16%±13%** |
| 0.1 | 50%±15% | 44%±15% | 25%±8% | 18%±13% |
| 0.3 | 58%±14% | 37%±15% | 24%±9% | 18%±13% |
| 0.6 | 66%±13% | 26%±13% | 28%±9% | 9%±9% |
| 1.0 | 58%±13% | 38%±16% | 23%±7% | 7%±8% |

**結論 — `c/b` 越高(合作門檻 `r*` 越大),善良策略越難立足。** 固定任一 churn 橫看,`nice%` 幾乎
單調隨 `r*` 反向遞減,排序對齊理論的 `cheap_voice < default < safety_net < ancient`。最乾淨的是
churn=0:**66% → 44% → 34% → 16%**,跨 preset 拉開 50 個百分點。唯一逆轉在 churn 0.6 的
`default`(26%)vs `safety_net`(28%),落在 CI95 重疊內。

→ **同一條 churn 軸,換個社會 preset(只調 payoff)就能讓相變/名聲依賴整體平移** —— 驗證統一框架
裡 `r*` 不只是個常數,而是可被社會結構推動的旋鈕。

## 策略擂台 — 主體換成「策略」:自己不吃虧 × 社會也好

前三張相圖問的是「**什麼社會**讓合作勝出」(環境當主體)。這一節把主體換成**策略本身**,
問一個個人決策者真正關心的問題:**哪個策略最值得我未來採用?** 標準是 **「自己不吃虧 + 社會不崩」**。

需要兩個不同的沙盒、合成兩條軸:

- **X 軸=自己不吃虧**(個人穩健):在 **16 策略生態混戰** 的 60 格命運(4 preset × 5 churn ×
  3 knockout)裡,採用某策略的個體表現 `composite = capital + survived`。散佈軸取**跨命運平均**
  (典型表現);另附 **保底 CVaR**(最壞 5 格平均 = `strategy_arena.py` 的 maximin 主指標)。
- **Y 軸=社會也好**(社會信任):把族群換成 **「全部都是策略 X」的單型社會**,跑到穩態量
  `good_share`(GOOD 名聲佔比 = 信任/合作率)。命運格 = churn(0/0.3/1.0)× knockout
  (none/−reputation/−private)= 9 格,取 **CVaR-maximin**(最壞 3 格 = 「最壞命運下社會還不崩嗎」)。
  *(注意:`nice%` 在單型退化恆 100%/0%,故社會福祉改用行為層的 `good_share`;preset 不納 —— 策略
  `decide()` 看不到 capital/存活參數,preset 只影響 capital、不影響信任率的決策動態。)*

### 怎麼重現(策略擂台)

```bash
# 1. 個人穩健擂台(純讀 60 格 melee phase_sweep JSON,含 per-strategy 明細)
docker compose run --rm simulator python -u experiments/strategy_arena.py

# 2. 單型社會福祉 sweep(遠端 ~5h、checkpoint 可續;9 格 × 16 策略 × 30 reps = 4320 runs)
docker compose run --rm \
  -e MONO_REPS=30 -e MONO_GENERATIONS=300 -e MONO_N=160 \
  -e MONO_CHURN_GRID=0.0,0.3,1.0 \
  -e MONO_KNOCKOUTS=none,-reputation,-private \
  -e RANDOM_SEED=12345 \
  simulator python -u experiments/monomorphic_sweep.py

# 3. 雙軸合成(純讀 melee + mono 兩份 JSON,切象限找甜蜜點)
docker compose run --rm simulator python -u experiments/sweet_spot.py
```

### 三個發現

1. **Sheriff 是唯一兼顧兩端的甜蜜點。** 掠食者(Prober/Cheater)個人典型表現最高(1.3–1.5),
   但全員採用 → 互相背叛、信任崩到 13%(9 格全低信任)。純善良群造就好社會,但個人典型表現
   剛好卡在中位下緣(左上)。**只有 Sheriff 同時站上「個人高於典型 + 社會高信任」。**

2. **Sheriff 的社會「九種命運全不崩」。** 全 Sheriff 社會的 `good_share` 在 churn 0→1、關名聲、
   關私記憶**全部 ~0.98 平坦不動**(它只讀名聲,全好社會裡人人是好人 → 永遠互相吹哨)。對比

3. **`maximin` 抓得出「平常還行、特定社會就崩」的脆弱。** Clannish 社會平均信任 0.67 看似尚可,
   但**最壞 3 格崩到 0.13**;Jacobin 平均 0.42、最壞格 0.13。用「最壞命運」而非「平均」評社會,
   才看得出這種隱藏脆弱 —— 這正是「社會不崩」要的保底視角。

### 一個必須誠實的張力:「不吃虧」有兩種意思

- **要「絕對最壞情況都安全」**(保底 CVaR > 0):**只有掠食者做得到**(Prober 0.15、Clannish、
  Whitewasher)。Sheriff 與所有善良策略保底 CVaR 都是 **0** —— 存在某種殘酷社會(關名聲的高流動
  都會)會把它們團滅。**想要絕對保命,就得當掠食者、接受地獄社會。**
- **接受「比多數人好」就夠**(跨命運典型表現):**Sheriff 是唯一甜蜜點** —— 不會是最有錢的
  (掠食者剝削賺更多),也確有罕見殘酷社會能毀掉你(這對所有好人都成立),但你會**過得比典型好,
  而且大家都學你這招,社會是最互信、最不會崩的**。

→ **這個沙盒給個人決策者的答案:做一個會懲罰壞人的好人(Sheriff)** —— 預設合作、對方佔便宜就果斷
反制。放棄的是「成為剝削別人的首富」與「絕對最壞情況保險」;換來的是「比多數人好的下場 + 一個
換成人人如此也不會崩壞的社會」。

> **前提(務必連同結論讀)**:X 軸沙盒是「16 策略生態混戰」(非兩兩對局、非 invasion),量的是
> 「在當前 16 策略共存社會中」採用某策略的穩健性,**非脈絡無關的內在價值**;增刪策略可能翻盤。
> Y 軸是「固定族群跑到穩態」的信任率,未含世代繁殖/死亡的長期演化(第二版才加 ESS 抗入侵)。

## 入侵 / ESS — 把族群放開繁殖:Sheriff 守得住嗎?救得回嗎?

上一節的甜蜜點是在**固定族群**(不繁殖、不死亡)裡量的,留了一個破口:走進幾個掠食者,Sheriff
壓得住嗎?反過來,在一個**掠食者當道的不信任世界**裡,少數 Sheriff 撐得起來、把社會翻成信任嗎?
這一節放開繁殖/死亡(資本加權繁殖 + 老化/破產死亡,世代重疊),問兩個鏡像問題:

- **防守(ESS 穩定)**:全 Sheriff 社會 + 少數掠食者入侵 → 入侵者份額被壓到 0 = Sheriff 是
  演化穩定策略(ESS)。
- **救贖(殖民翻轉)**:掠食者多數的世界 + 少數 Sheriff → Sheriff 能否從少數茁壯、把社會的
  `good_share`(GOOD 名聲佔比 = 信任率)從低谷拉回 ~1?要看**世代軌跡**。

防守與救贖是同一對策略的鏡像(誰當原住民、誰當入侵者)。掃 4 掠食者 × 雙向 × 入侵種子
{3%,5%,10%,20%} × 9 命運(3 churn × 3 knockout)× n=30 = **8640 runs**。

### 怎麼重現(入侵 / ESS)

```bash

docker compose run --rm \
  -e INV_REPS=30 -e INV_GENERATIONS=300 -e INV_N=160 \
  -e INVADER_FRACS=0.03,0.05,0.10,0.20 \
  -e INV_CHURN_GRID=0.0,0.3,1.0 \
  -e INV_KNOCKOUTS=none,-reputation,-private \
  -e INV_PREDATORS=Cheater,Prober,Whitewasher,Clannish \
  -e RANDOM_SEED=12345 \
  simulator python -u experiments/invasion.py
```

### 防守:Sheriff 是 ESS —— 但有一個條件

入侵者末份額被清到 0 的比例(`invader_extinct`,n=30、所有種子 3→20% × 所有 churn 聚合):

| 對手 | `none` | `−private` | `−reputation` 蒙眼 |
| :-- | :--: | :--: | :--: |
| Cheater | **1.00 全守住** | **1.00** | 0.00–0.33 多數**反被入侵** |
| Prober | **1.00** | **1.00** | 0.00–0.33 反被入侵 |
| Whitewasher | **1.00** | **1.00** | 0.00–0.50 反被入侵 |
| Clannish | **1.00** | **1.00** | 0.00–0.53 反被入侵 |

**只要名聲管道看得見(`none` / `−private`),全 Sheriff 社會就是磐石** —— 四個掠食者、入侵種子
大到 20%、所有流動度,**全部 100% 守住**(每格 30/30 reps 都 `resisted`)。私人記憶關掉不影響,
因為 Sheriff 根本不靠它 —— **它只讀公共名聲**。

**但 ESS 不是無條件的:關掉名聲(`−reputation`),Sheriff 連自家都守不住。** 蒙眼後它認不出
掠食者、把對方當好人吹哨幫忙 → 被剝削 → 守住率崩到 0.0–0.5,多數格反被入侵。
**Sheriff 的 ESS 地位,完全押在「名聲看得見」這一個條件上。**

### 救贖:需要臨界質量,而且做得到

少數 Sheriff 入侵掠食者世界、能不能翻成信任?**能,但要夠多人**(`none`-knockout,「✔ 真翻轉」
= 多數 run `redeem_win` 且 `good_share` 由低谷翻過 0.5):

| 對手 | churn 0.0 村莊 | churn 0.3 | churn 1.0 都會 |
| :-- | :--: | :--: | :--: |
| Cheater | **10% ✔** | 20% ✔ | 20% ✔ |
| Prober | **10% ✔** | 20% ✔ | 20% ✔ |
| Clannish | ✗(20% 仍卡共存) | 20% ✔ | 20% ✔ |
| Whitewasher | ✗ | 份額勝但信任未真翻 | 同左 |

- **3~5% 的零星 Sheriff 一律失敗** —— 還沒彼此會合、形成互助前就被掠食者磨到滅絕。要約 **1/5
  的人**一起,才站得穩、滾雪球翻盤。「一個人改變不了世界,但一場運動可以」的數學版。
- **乾脆背叛的掠食者(Cheater/Prober)最好救**:被標 BAD 最快,10% 就能翻村莊、20% 翻所有流動度。
- **Whitewasher(洗白者)最難救** —— 它「好就背叛、壞就洗白」專門污染 Sheriff 賴以判斷的名聲管道,
  讓 `good_share` 永遠假性停在 ~0.55(看似還行、其實是被刷出來的)。連 20% Sheriff 也只能把份額
  推到 0.4–0.6,信任翻不乾淨。
- **Clannish(排外者)在村莊(churn 0)最難撼動** —— 它在固定圈子裡是稱職好鄰居,20% Sheriff 仍
  卡在共存;但高流動下(churn 1.0)它的「認親」失靈、20% 就翻得動。關掉私記憶(`−private`)廢掉
  它的認親能力 → 連村莊都救得回(翻轉率 0.47→0.83)。
- **關掉名聲(`−reputation`)→ 救贖全盤失敗**(翻轉率平均 0.03、Sheriff 末份額 ~0)。

### 必須誠實的範圍與張力

- **ESS 是有條件的**,不是無條件:它成立於「名聲可觀測」的前提下。標題寫「Sheriff 是 ESS」時
  必須連這個前提一起講,否則就是過度宣稱。
- **份額翻轉 ≠ 信任翻轉**:Whitewasher 世界裡 `good_share` 被洗白刷成假性 ~0.55,
  「`redeem_win`(份額勝)」未必等於「社會真的變可信」。兩者會分岔,本節分開標示。
- **只測 default preset、且為兩物種對局**(resident + invader),非 Sheriff 入侵 16 策略混合
  生態。資本加權繁殖下 preset 會影響動態,結論別外推到其他 payoff / 多物種雜燴。
- **臨界種子是離散掃描**(3/5/10/20%),真正的臨界值落在格與格之間;近臨界格方差最大,故看
  30 reps 的結局票數而非單一 run。
- **下一步(#6 第三方制度懲罰)**:即使 Sheriff 達 ESS,仍要觀察「系統主動淘汰 BAD」這類外部制度
  對生態的影響 —— 已完成,見下節。

## 第三方制度懲罰 — 制度能取代名聲嗎?

前面所有合作都靠三大**自發**機制:結伴(`r`)、私記憶(`w`)、名聲(`q`)。但現代社會最有當代感的
一條 —— **第三方制度懲罰**(Nowak 第五法則)—— 還沒點亮:法律、平台封號、信用黑名單,把判定為 BAD
的人**由系統主動淘汰**,不必等受害者自己報復。這一節加上這個機制(每回合以 `INSTITUTION_STRENGTH`
的機率移除 BAD,可選 `INSTITUTION_FALSE_POSITIVE` 冤枉 GOOD),問三個問題:制度能否在都會**取代名聲**?
能否**廢掉洗白套利**?**誤判率**多高會反噬?

引擎僅加一支分支(死亡階段:自然死亡優先,存活者再過制度淘汰一關,走既有資本加權繁殖),預設
`INSTITUTION_STRENGTH=0` 完全等同現狀。掃 **assortment{0,0.3,0.6}** × strength × churn ×
{none,−reputation} × {全 16, 去 Whitewasher} + 誤判率敏感度線 = **5520 runs(n=30)**,
2026-06-04 於遠端 20 核跑完(顯式 `ASSORTMENT`,不經 `.env`)。下表主數據取 **assortment 0.0
(well-mixed)** —— 結構不幫忙、最能凸顯「制度替代名聲」的純效果;跨 assortment 穩健性見發現 1。

### 怎麼重現(第三方制度)

```bash
docker run --rm -v "$PWD/output:/app/output" \
  -e INST_REPS=30 -e INST_GENERATIONS=300 \
  -e INST_ASSORT_GRID=0.0,0.3,0.6 \
  -e INST_STRENGTH_GRID=0.0,0.02,0.05,0.1,0.2 \
  -e INST_CHURN_GRID=0.0,0.3,1.0 \
  -e INST_KNOCKOUTS=none,-reputation \
  -e INST_SETS=full,no_whitewasher \
  -e INST_FP_GRID=0.0,0.05,0.1,0.2,0.4 \
  -e RANDOM_SEED=12345 -e JOBS=20 \
  eos-sim python -u experiments/institution_sweep.py
```

> 用 `docker run`(顯式 `-e ASSORTMENT/INST_*`)而非 `docker compose run` —— 後者會經 `env_file: .env`
> 默吃 `ASSORTMENT=0.6`,污染 well-mixed 基準(本研究踩過的坑,故主數據一律顯式傳參)。

### 三個發現

**1. 制度只要很弱就能在都會取代名聲。** 都會(churn 1.0)**關掉自發名聲**後,合作崩到 **1%**;但只要
制度強度 **0.05**(每回合淘汰 5% 的 BAD),`−reputation` 的合作就從 **1% 回到 70%**,強度 0.2 攀到 88%。
**「只有制度、沒有自發名聲」就足以撐起都會合作** —— 制度是名聲的有效替代品。

| 制度強度 | 都會 `−reputation` nice%(assort 0, full, n=30) |
| :--: | :-- |
| 0.0 無制度 | **1%**(關名聲 → 崩潰) |
| 0.02 | 8% |
| **0.05** | **70%**(已救回) |
| 0.1 | 72% |
| 0.2 | 88% |

**跨結構穩健**:這條救援不靠特定 assortment。固定強度 0.05、都會、關名聲,`nice%` 在
assort 0 / 0.3 / 0.6 分別為 **70% / 74% / 81%** —— 結構越強,弱制度的救援越給力,但**即使
well-mixed(assort 0)、結構完全不幫忙,5% 的制度淘汰率照樣把崩潰的都會合作救回 70%。**

**2. 制度關閉洗白套利窗口。** 無制度時 Whitewasher(洗白者)在都會還有 **~15%** 立足;制度強度一到 **0.05**,
它的份額就崩到 **0%** —— BAD 一被標記就被系統清掉,「好就背叛、壞就洗白」的套利窗口被關死。
(去掉 Whitewasher 的對照組結論一致,確認這是針對洗白者的壓制,非整體假象。)

**3. 誤判率有一道銳利紅線。** 固定強度 0.1、都會、關名聲,掃冤枉 GOOD 的誤判率:**5% 還行(合作 76%),
但一旦 10% 的好人被冤枉淘汰,合作從 76% 崩到 2%。** 制度的正當性押在低誤判率上 —— 一個亂抓好人的
系統,比沒有系統更糟。

| 誤判率 fp | nice%(強度 0.1, 都會, 關名聲, assort 0) |
| :--: | :-- |
| 0.0 完美執法 | 72% |
| 0.05 | 76% |
| **0.1** | **2%(崩潰)** |
| 0.2 / 0.4 | 0% |

### 一句話

> **制度懲罰是名聲的有效替代品,而且很便宜 —— 都會裡只要 5% 的淘汰率,就能在完全沒有自發名聲時
> 撐起合作、並清除洗白者。但它的正當性押在「不冤枉好人」上:誤判率一過 ~10%,整個系統反而把合作
> 推向崩潰。** 對應現實:強而精準的執法/平台治理能取代口碑撐住大型匿名社會;但寧枉勿縱的執法
> 會比放任更快摧毀信任。

> **範圍**:制度=淘汰(非資本罰款)、固定 default preset;與自發名聲可疊加(本節主要看「只剩制度」
> 的極端以凸顯替代性)。
